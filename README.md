# Portfolio ปรินทร ทุนนะ (ทิน)

เว็บไซต์ Portfolio แบบ static (HTML, CSS, JavaScript) ไม่ต้องติดตั้งอะไรเพิ่ม

## โครงสร้างไฟล์

```
index.html          หน้าเว็บหลัก
css/style.css       สไตล์ทั้งหมด
js/main.js          ดูภาพขยาย และปุ่มคัดลอกข้อมูลติดต่อ
assets/img/         รูปภาพทั้งหมด
```

## วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub เช่น `portfolio`
   (ถ้าตั้งชื่อว่า `ชื่อผู้ใช้.github.io` เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io`)
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ลากวางในหน้าเว็บ GitHub ได้เลย)
3. ไปที่ **Settings → Pages**
4. ที่ **Source** เลือก **Deploy from a branch** เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
5. รอประมาณ 1-2 นาที แล้วเปิดลิงก์ที่ GitHub แสดงให้

## วิธีแก้ไขข้อมูล

- ข้อความทั้งหมดอยู่ใน `index.html` ค้นหาแล้วแก้ได้เลย
- เปลี่ยนสีที่ส่วน `:root` ตอนต้นของ `css/style.css`
- เพิ่มกิจกรรมใหม่: คัดลอกบล็อก `<figure class="card">...</figure>` ใน `index.html` แล้วเปลี่ยนรูปกับข้อความ
- เพิ่มรางวัลใหม่: แก้ในส่วน ACHIEVEMENT ของ `index.html` (การ์ดรางวัลและแกลเลอรีรูป)
- ปรับระดับทักษะ: แก้จำนวน `<i class="off">` ในแต่ละแถวของส่วน SKILLS

## หมายเหตุเรื่องข้อมูลส่วนตัว

หน้าเว็บนี้เปิดให้ทุกคนเห็นได้ ถ้าไม่ต้องการแสดงเบอร์โทร ให้ลบแถว `โทร` ในส่วน CONTACT ของ `index.html`
